AI 助手 / 源码安装 · 试验方式

复制一句话，让 AI 帮你安装。

在要安装 Stella 的电脑上打开支持操作本机的 AI 助手，复制下方对应系统的指令，粘贴到对话框并发送。助手会从 GitHub 获取源码，检查环境、准备依赖并建立客户端入口。

什么是 AI 助手（AI Agent）？ 它不仅能回答问题，还能在获得许可后操作电脑、运行命令并完成多步骤任务。国内常见的有 腾讯 WorkBuddy；通义灵码和 TRAE 的智能体模式更适合熟悉开发工具的用户。

请使用支持本机文件和终端操作的电脑版，并按提示授权。豆包等 AI 的不同产品或模式能力可能不同；如果只能聊天、不能操作这台电脑，就无法代为安装，可使用下方安装包。

源码安装为试验方式，首次安装需要网络和额外空间。更新时获取 GitHub 主分支源码，不需要重新下载安装包；本机不会自动更新。

03 / 安装

跟着这三步即可

  1. 01

    下载一个压缩包

    选择夸克网盘或 GitHub，下载一个完整 ZIP。

  2. 02

    全部解压

    右键 ZIP，选择「全部解压」，打开解压后的 Stella-Windows-1.1.8-offline 文件夹。

  3. 03

    双击开始安装

    退出正在运行的 Stella，双击 开始安装.cmd，按提示完成安装。

Stella-Windows-1.1.8-offline /↳ 开始安装.cmd 双击这个文件↳ 使用说明.txt↳ 组件 ZIP 与安装程序 自动读取，无需操作

请先完整解压，再运行安装文件。保留解压后的全部文件；其中的组件 ZIP 不用再次解压。

安装准备与其他下载方式

适用 Windows 10 1809+ / Windows 11，暂不支持 ARM、32 位及 Windows Server。系统需具备 Microsoft Edge WebView2 运行时；离线包包含 Stella 组件，但 AI、法院等联网功能仍需网络。

此包已包含智能立案与新建对方当事人修复，通过构建环境中的安装、启动和保留资料升级测试，仍待 Windows 10/11 实机验证。已有资料独立保留，升级前建议备份重要资料。
