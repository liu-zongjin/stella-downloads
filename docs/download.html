03 / 安装

跟着这三步即可

  1. 01

    下载一个压缩包

    在夸克下载完整 ZIP，无需逐个选择组件。

  2. 02

    全部解压

    右键 ZIP，选择「全部解压」，打开解压后的 Stella-Windows 文件夹。

  3. 03

    双击开始安装

    退出正在运行的 Stella，双击 开始安装 Stella.cmd，按提示完成安装。

Stella-Windows /↳ 开始安装 Stella.cmd 双击这个文件↳ 安装说明.txt↳ 安装资源 / 自动读取，无需操作

请先完整解压，再运行安装文件。保留「安装资源」文件夹，其中的组件 ZIP 不用解压。

安装准备与其他下载方式

适用 Windows 10 1809+ / Windows 11，暂不支持 ARM、32 位及 Windows Server。系统需具备 Microsoft Edge WebView2 运行时；离线包包含 Stella 组件，但 AI、法院等联网功能仍需网络。

此包含启动交接与文件夹选择修正，等待 Windows 实机验证。已有资料独立保留，升级前建议备份重要资料。

也可使用 1.1.6 在线引导器，安装时需联网下载组件。
