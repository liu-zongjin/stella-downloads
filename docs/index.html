一张网电子送达

手机号核验后，
送达文书自动归案。

从 iPhone 收到电子送达短信，到文书落进本地案件文件夹。向下滚动看一次完整的成功流程。

  1. 手机收到送达短信

    法院通过 12368 发来电子送达通知，短信中包含法院、案号和文书查阅链接。

  2. 自动同步到司法短信

    手机短信经 iCloud 同步到 Mac「信息」。开启自动扫描后，Stella 会读取新通知，将其导入「司法短信」列表。

  3. 识别内容，匹配案件

    提取法院、案号和通知事项，再用案号匹配本地已有的案件。

  4. 完成收件手机号核验

    遇到要求手机号核验的送达页，Stella 会使用已配置的收件号码尝试核验。

  5. 从送达链接获取文书

    核验通过后，从短信里的送达链接提取可下载的文书附件。

  6. 归入本地案件

    文书下载后自动归入已匹配案件的文件夹，打开案件就能继续处理。

自动归档需要哪些条件？

需开启 iPhone 到 Mac 的 iCloud 信息同步，授权 Stella 读取「信息」、启用自动扫描，并设置识别服务和收件手机号。导入时间取决于 iCloud 同步和 Stella 的扫描间隔。示例中的案件已绑定可用的本地文件夹。

无法匹配案件、核验失败或需要本人登录时，按 Stella 的提示处理。法院账户同步和立案辅助也需要本人按应用提示核对。

知识与阅读

原文和批注，
随时对照。

邮箱与发票

从处理邮件，到归集票据。

接入 QQ 邮箱、腾讯企业邮箱与网易企业邮箱，在同一工作空间阅读、搜索和发送邮件，预览和下载附件。

按邮箱、时间和关键词查找 PDF、OFD、XML 等票据，核对开票时间、金额和来源邮件，筛除已导出记录后批量打包。

可按月扫描上一个自然月，生成本机 ZIP。历史记录保留导出结果，方便检查失败状态和补查。

06 / 你可能想了解

开始之前，
再了解一点。

这是什么？我可以直接使用吗？＋

Stella 面向律师与法务人员，连接案件管理、法院通知、知识阅读与办公工具。下载后即可建立自己的案件和知识库，邮箱、法院与 AI 功能按需配置。律所内部审批、会议和设备接入可联系作者定制。

支持哪些电脑？＋

Mac 版支持 Apple 芯片和 Intel 芯片，要求 macOS 12 或更新版本。Windows 版仍在开发中，现为测试版，存在组件下载慢、安装完成后部分功能组件无法正常使用等问题；适用于 Windows 10 1909+ / Windows 11 的 Intel、AMD 64 位电脑，暂不支持 ARM、32 位和 Windows Server。

这是开放源代码的项目吗？＋

当前 1.1.8 的原创源码按 AGPL v3（仅第 3 版）提供，第三方材料遵循各自许可。查看应用源码与许可 ↗。历史安装包请以包内随附许可为准；本分发仓库的旧许可不限制新 Windows 包所附 AGPL 已授予的权利。

短信识别和法院同步如何开始？＋

Mac 版可使用已同步到「信息」中的司法短信，需开启相关同步、授予读取权限并配置识别服务；Windows 版支持粘贴文本、TXT 或截图，预览确认后导入。一张网功能需登录自己的人民法院在线服务账户。涉及登录、核验或最终提交的步骤，按应用提示由本人完成。

AI 和其他联网功能需要另外配置吗？＋

需要。AI、邮箱、法院服务及 MCP 等功能使用你自己的账号或密钥。Windows 引导器会准备浏览器、文字识别和文档转换组件；Mac 的部分联网工具仍需按功能指引配置 Chrome 等外部应用。

如何更新或反馈问题？＋

源码版更新需自行向 AI 助手发起。Windows 安装方式及测试版说明请查看下载指引。升级前请备份重要资料；旧 Mac 版若在应用包内保存过附件或导出文件，请额外复制旧 Stella.app 留存。如遇问题，请前往 GitHub Issues，说明应用与系统版本，避免上传敏感资料。
