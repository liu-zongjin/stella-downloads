重要提示 / RELEASE STATUS

Windows 版本仍在开发中，现为测试版。

  • 组件下载慢：首次安装及后续更新可能需要联网下载浏览器、文字识别等依赖组件，下载速度较慢或中途中断。
  • 部分功能可能不可用：安装完成后，个别依赖组件可能无法正常安装、无法启动，导致对应功能无法正常使用。
  • 建议：如无 Windows 环境的特殊需要，日常使用请优先选择 Mac 版；试用 Windows 版时请在升级前备份重要资料。

AI 助手是什么？能直接操作电脑的 AI。你授权后，它可以下载文件、安装软件、运行命令，不只是回答问题。
